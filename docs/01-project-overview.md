# CodeAtlas - Project Overview

## Vision
An AI-augmented monorepo onboarding engine and engineering intelligence platform that reduces developer onboarding time from weeks to hours by automatically mapping, explaining, and simulating complex codebases through interactive visual graphs, temporal time travel, and verifiable credentials.

## Core Problem
- Documentation goes stale instantly in fast-moving codebases.
- New developers spend weeks understanding component hierarchies and dependency graphs (Spatial Blindness).
- Architecture visualizers operate in a historical vacuum without knowing author churn or commit velocity (Temporal Blindness).
- First-time open source contributors struggle to find safe, isolated issues and understand PR workflows.
- Online portfolio claims and credentials lack mathematical cryptographic verification.

## Solution: The Unified Intelligence & Credential Ecosystem
CodeAtlas connects to GitHub, analyzes repository topology and telemetry, and generates:
1. **Interactive Architecture Graph (CodeAtlas)** - Node-based topological visualization of modules, services, API routes, and dependencies via React Flow.
2. **Issue-to-Code Mapping & OpenSourceMapper** - 6-signal hybrid ranker and AST subgraph isolation scorer providing 3-step contributor blueprints and prerequisite checklists.
3. **Software Time Machine & Archaeology (Chronos)** - Timeline scrubber, commit hotspot heatmaps, architectural archaeology ("Why was this changed?"), and what-if refactor mutation simulations.
4. **Conversational Database Time Machine (OmniQuery)** - Model discovery, natural-language to SQL workbench, cross-engine breaking route analysis, and sandboxed execution with rollback guarantees.
5. **Active Editor Telemetry (WakaTime-Style)** - Local heartbeat ingestion mapping active focus minutes to AST nodes to detect Cognitive Friction Index (CFI) hotspots.
6. **GitReverse & AI Context Packager** - Hierarchical AST token budget optimizer generating `AGENTS.md`, `.cursorrules`, and `llms.txt`.
7. **CodeAtlas Flight Simulator** - In-browser virtual Git shell and PR bot sandbox training contributors on branching, code reviews, and merge conflict resolution.
8. **Holopin-Style Verifiable Profile Badges** - Dynamic, embeddable SVGs with Ed25519 cryptographic signatures and a public verification portal.

## Target Users
- Engineering teams onboarding new hires onto complex monorepos.
- Student coding clubs and first-time open-source contributors learning Git workflows.
- Open-source maintainers seeking to automate issue triage and contributor onboarding.
- Platform and architecture teams enforcing modular boundaries and mitigating knowledge silos.
